# Supermarket Careers website

## Build
- Replace the blank page with a complete, image-led recruitment experience for Naivas, Quickmart, and Carrefour.
- Use the generated supermarket team photograph as the full-width opening background, with prominent brand names and a clear jobs call to action.
- Present the three supermarkets as distinct branded opportunities with direct official application links.
- Add an interactive vacancies explorer covering cleaners, cashiers, storekeepers, drivers, loaders, marketers, sales attendants, chefs, warehouse supervisors, and guards.
- Complete the journey with a simple hiring-process section, application guidance, and a concise footer.

## Visual direction
- Modern editorial layout using Naivas green, Quickmart red, and Carrefour blue as distinct accents, balanced by charcoal and warm white.
- No gradients; strong typography, crisp borders, restrained motion, and mobile-friendly navigation.
- Use the generated photography prominently and avoid imitating any official brand logo.

## Technical details
- Keep the experience frontend-only; outbound Apply buttons open each supermarket's official careers/application destination in a new tab.
- Add route-specific search/social metadata and accessible labels, focus states, imagery, and reduced-motion handling.
- Verify the finished page in desktop and mobile layouts and resolve any build/runtime errors.
